# 進行記録（ストップウォッチ）

講演や講義の進行を、ストップウォッチ感覚で手動記録できるブラウザ用ツールです。サーバーは不要で、HTML と JavaScript だけで動作します。

## 主な機能

- 経過時間の計測（開始・停止・リセット）
- プリセットボタンを押すと、その時点の経過時間と時刻を記録
- 記録の CSV 保存（Excel やスプレッドシートで開けます）
- プリセットは `presets.js` で設定可能
- 時刻は日本標準時（JST, UTC+9）に固定して表示・保存

## ファイル構成

```
.
├── index.html    ストップウォッチ本体
├── presets.js    プリセット設定（編集するのはこのファイル）
├── LICENSE       MIT ライセンス全文
└── README.md     このファイル
```

## 使い方

1. `index.html` をブラウザで開きます。
2. 講演開始に合わせて「開始」を押します。
3. 項目が変わるタイミングでプリセットボタンを押すと、経過時間と時刻が記録されます。
4. 終了後、「CSV保存」を押してファイルを保存します。

### ボタン一覧

| ボタン | 動作 |
| --- | --- |
| 開始 / 停止 | 経過時間の計測を開始・一時停止します |
| リセット | 経過時間と記録をすべて消去します（確認あり） |
| CSV保存 | 記録をCSVファイルとしてダウンロードします |
| プリセットボタン | 押した時点の経過時間と時刻を記録します |

## プリセットの変更

`presets.js` を開き、項目名を編集して保存します。

```js
window.PRESET_LIST = [
  "導入",
  "本題1",
  "本題2",
  "質疑応答",
  "まとめ"
];
```

編集後は、ブラウザでページを再読み込み（F5）してください。`presets.js` が見つからない場合は、`index.html` 内の初期値が使われ、ステータス欄に理由が表示されます。

## CSVの形式

```csv
項目,経過時間,時刻（JST）
"導入","00:00:00","2026-10-13 09:00:00"
"本題1","00:12:34","2026-10-13 09:12:34"
```

- 文字コードは UTF-8（BOM 付き）です。Excel で開いても日本語が文字化けしません。
- ファイル名は `log_YYYYMMDDHHMMSS.csv` の形式で、保存時刻（JST）が付きます。

## 動作環境

モダンブラウザ（Chrome、Edge、Firefox、Safari の最新版）で動作します。スマートフォンでも利用できます。

## 公開方法（GitHub Pages）

1. GitHub でリポジトリを作成し、`index.html`、`presets.js`、`LICENSE`、`README.md` をアップロードします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` に設定して保存します。
4. `https://<ユーザー名>.github.io/<リポジトリ名>/` で閲覧できます。

プリセットを変更した場合は、`presets.js` を更新してコミットしてください。

## 注意事項

- **記録はブラウザ内にのみ保持されます。** ページを閉じると消えるため、講演後に必ず CSV を保存してください。
- **経過時間** は `performance.now()` で計測しているため、端末の時刻設定を変更しても影響を受けません。
- **時刻** はシステムの瞬間を取得し、JST に変換して表示・保存します。
- 画面がスリープすると、ブラウザのタイマー動作が止まる場合があります。長時間の講演では、スリープしない設定にしてください。
- 公開リポジトリに置く場合、プリセット内容やファイルは誰でも閲覧できます。
